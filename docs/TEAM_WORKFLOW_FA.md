# Last Signal — راهنمای توسعه‌ی اتاق‌ها برای تیم

> وضعیت: بر اساس `develop` بعد از مرج جدایی مطلق اتاق‌ها
> (مرج‌کامیت `3b2efa8`، ۲۳ نوامبر ۲۰۲۶). هر اتاق پوشه‌ی کاملاً جدا دارد و
> هیچ فایلی با اتاق دیگر شریک نیست — فقط بافت‌ها و اسپرایت‌های `assets/`
> مشترک‌اند، چون آرت‌اند نه منطق.

## اتاق‌ها و پوشه‌هاشان

هر نفر فقط پوشه‌ی اتاق خودش را دست می‌زند — هم صحنه، هم اسکریپت:

| اتاق | پوشه |
|---|---|
| کنترل مرکزی | `rooms/command_center/` |
| بخش پزشکی | `rooms/medical_wing/` |
| آزمایشگاه | `rooms/laboratory/` |
| نیروگاه | `rooms/engine_room/` |
| محوطه‌ی مخابرات | `rooms/communications/` |

مسیر کامل: `scenes/levels/rooms/<room>/` برای صحنه‌ها و
`scripts/levels/rooms/<room>/` برای اسکریپت‌ها. توی هر پوشه: اسکریپت
اتاق، کپی خودش از سیم‌کشی، بازیکن، مأموریت، رادار و افکت حلقه، لانچر
خودش (`play_<room>.tscn`) و کپی صحنه‌های تعاملی و دشمنی که استفاده
می‌کند. همه‌چیز با مختصات محلی تعریف می‌شود — مبدأ (۰٬۰) خود اتاق —
و هیچ اتاقی نمی‌داند توی ایستگاه کجاست؛ فقط `level_01` آفست‌ها را
می‌داند.

## شروع کار روی یک اتاق

```sh
git checkout develop
git pull
git checkout -b room/<room>-<کاری که می‌کنی>
```

## اجرای فقط همان اتاق، برای تست

```sh
godot --path . scenes/levels/rooms/<room>/play_<room>.tscn
```

توی ادیتور گودو (نسخه‌ی ۴٫۷٫۲) هم کافی است `play_<room>.tscn` را باز
کنی و F6 بزنی — دیگر `--room=` لازم نیست. جدا که بازی می‌کنی، درهای
خروجی مهر و موم‌اند.

## تست‌ها، قبل از پول‌ریکوئست

```sh
godot --headless --path . --script res://scripts/tests/test_rooms.gd
godot --headless --path . --script res://scripts/tests/test_runner.gd
```

هر دو باید سبز باشند (آخرین وضعیت روی `develop`: ‏۶۶۱/۶۶۱ و
‏۳۲۸/۳۲۸). بعد:

```sh
git push -u origin room/<room>-<کاری که می‌کنی>
```

و PR به `develop` — نه `main`.

## سه قانون

1. **فایل‌های مشترک را دست نزن:** `level_01.gd` و `level_wiring` و
   `level_data` و `floor_builder` و `medical_data`، و پوشه‌ی اتاق‌های
   دیگر.
2. **باگ چیز مشترک را توی کپی خودت فیکس نکن:** اگر باگی توی بازیکن،
   سیم‌کشی یا سیستم مشترک دیدی، به اهورا بگو — چون باید توی هر ۵ کپی
   اعمال شود. کپی‌ها می‌توانند از هم دور شوند و این هزینه‌ی جدایی
   مطلق است.
3. **خروجی‌ها (`exits()`) را دست نزن** تا وقتی وصل کردن اتاق‌ها شروع
   شود. اتاق‌ها هنوز به هم وصل نیستند؛ وصل کردن بعداً کار اسمبلر است
   (باز کردن خروجی‌های جفت)، نه تغییر کد اتاق‌ها.

## نکته‌ها

- فقط اتاق کنترل مرکزی قابل‌تمام‌کردن است؛ چهار اتاق دیگر فعلاً
  گشت‌وگذار و گشت ربات‌اند.
- ابزار، پازل یا کاراکتر تازه را توی صحنه یا `_ready` اتاق خودت اضافه
  کن؛ کافی است توی گروه درست باشد (`puzzles`، ‏`towers`، ‏`enemies`،
  ‏`interactable`) — سیم‌کشی خودش پیدایش می‌کند و وصلش می‌کند.
- جزئیات معماری کامل در `docs/ARCHITECTURE.md` است.
